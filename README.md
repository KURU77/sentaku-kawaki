# 洗濯乾きナビ

**室温と湿度** を入れるだけで、洗濯物の乾きやすさ（0〜100）と、乾くまでの目安時間がわかるアプリです。

**→ https://kuru77.github.io/sentaku-kawaki/**

依存ライブラリなし・ビルド不要。入力値はブラウザの localStorage にだけ保存され、外部へは一切送信しません。オフラインでも開けます。iPhone は Safari の共有メニューから「ホーム画面に追加」でアプリとして使えます。

## できること

- **乾きやすさ指数** — 0〜100 と5段階（ほとんど乾かない〜とてもよく乾く）
- **Tシャツが乾くまでの時間** と、部屋干し臭の注意（5時間超えで警告）
- **衣類別の目安** — 下着・Tシャツ・タオル・バスタオル・パーカー・ジーンズ
- **干し方の条件** — 場所（室内／屋外日陰／屋外日なた）、扇風機・エアコン除湿・除湿機、量と間隔
- **アドバイス** — 5時間で乾かすのに必要な湿度、家電を使った場合の短縮見込み、干し方のコツ
- **乾きやすさマップ** — 室温×湿度の色分け図。タップ／ドラッグで条件を切り替え、Tシャツ5時間ラインも表示
- 飽差・絶対湿度・露点の表示

## 計算のしくみ

洗濯物が乾く速さは、空気があと何グラムの水蒸気を含めるか（**飽差**, g/m³）にほぼ比例します。

```
飽和水蒸気圧 es = 6.1078 × 10^(7.5T / (T + 237.3))   [hPa]（Tetens の式）
飽差 D        = 216.7 × es × (1 − RH/100) / (T + 273.15) [g/m³]
乾きやすさ    = min(100, D / 15 × 100)
乾燥時間      = 48 × 衣類係数 × 場所係数 × 風係数 × 量係数 / D  [時間]
```

基準は「脱水後のTシャツ・室内・無風・ふつうの量」で、20℃・湿度60% のとき約7時間です。

| 条件 | 係数 |
|---|---|
| 屋外・日陰 / 日なた | 0.6 / 0.35 |
| 扇風機 / エアコン除湿 / 除湿機 | 0.55 / 0.65 / 0.45 |
| 少なめ / 多め | 0.85 / 1.3 |

係数は一般的な目安から置いた概算値です。実際の時間は生地・脱水時間・部屋の広さで前後します。
